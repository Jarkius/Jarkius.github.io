Claude Code Statusline — 6-line Dashboard

A statusLine command script for Claude Code that spreads session info across 6 lines instead of cramming it into one, so nothing gets truncated in narrow panes. Every line leads with a fixed icon, and lines with no data (like rate limits outside a Claude.ai subscription) are omitted entirely.

📁 wakeup-call-youtube 📝 statusline-multiline 🌿 main ● ✅ #42 📦 Jarkius/wakeup-call-youtube 📂 /Users/jarkius/workspace/dev/wakeup-call-youtube 🕐 12:23:19 ⏱ 12m 🤖 Claude Sonnet 5 🧠high 📊 [██████░░░░░░░░░░░░░░] 30% 60k/200k 🔥 5h:30%(↻7h36m) 7d:12% 📈 💰 $0.42 💬 5 ✏ +20/-3 ⚡ 5m (39%)

What each line shows

LineIconContents
1📁Project name, session name (set via /rename)
2🌿Git branch, dirty status, ahead/behind, PR/MR badge, worktree name, clickable repo + directory links
3🕐Time, session duration, model, effort/mode flags, active subagent name, vim mode
4📊Context window usage bar, percentage, tokens used / max
5🔥5-hour and 7-day rate-limit usage with reset countdown (Claude.ai subscribers only — line omitted otherwise)
6📈Session cost, turn count, lines changed, API-time share

Setup

  1. Save the script to ~/.claude/statusline.sh and chmod +x it.
  2. Point Claude Code at it in ~/.claude/settings.json: 
    {
  "statusLine": {
    "type": "command",
    "command": "/Users/you/.claude/statusline.sh"
  }
}
  3. Requires jq and bc (brew install jq bc on macOS — bc is usually preinstalled).
